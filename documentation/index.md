# Axiomatic

Describe a hierarchy once, and let its composition carry the layout through changes in content and available space.

An article has a headline, a byline, and a body. A result has supporting facts and a next action. You already know which things belong together. Axiomatic aims to make that understanding enough to get useful spacing and responsive behavior, without repeatedly tuning each boundary.

This is the working guide for a library in development. Its examples execute a small candidate foundation; the public API is still being shaped.

[Start with the primitives](onboarding/index.md), then [compose them through a change of width](onboarding/changing-space.md). The [investigation study](onboarding/investigation.md) puts those ideas beside a real interface problem.

[Open the playground](/_media/documentation/playground/index.html) to compose your own. Keep named drafts in your browser, compare the same composition in a wide card and a narrow rail, and share a fixed snapshot of what you made. The guide and playground use the same primitives.
